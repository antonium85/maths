Équation de droite : QCM chronométré

Séries de questions à choix multiples, une seule réponse correcte à chaque fois. Chaque erreur est corrigée avec la méthode, puis ajoutée à ton carnet pour être retravaillée plus tard.

Rappels : formules et astuces
  • Équation réduite d’une droite non verticale : y = mx + p. m est le coefficient directeur (la pente), p l’ordonnée à l’origine : la droite coupe l’axe des ordonnées en (0 ; p).
  • Droites particulières : horizontale y = k (m = 0) ; verticale x = k (pas de coefficient directeur, donc pas d’équation réduite).
  • Avec deux points A et B (xA ≠ xB) : m = (yB − yA) / (xB − xA). Ensuite p = yA − m × xA.
  • Appartenance : le point M(x ; y) est sur d : y = mx + p si et seulement si y = m × x + p est vrai.
  • Parallèles : même coefficient directeur (m = m′). Perpendiculaires (repère orthonormé) : m × m′ = −1, donc m′ = −1/m.
  • Équation cartésienne : ax + by + c = 0, avec (a ; b) ≠ (0 ; 0). Vecteur directeur u(−b ; a). Vecteur normal n(a ; b). Si b ≠ 0 : m = −a/b et p = −c/b.
  • Droite définie par un point et un vecteur normal : la droite passant par A(xA ; yA) de vecteur normal n(a ; b) a pour équation a(x − xA) + b(y − yA) = 0, soit ax + by + c = 0 avec c = −(a × xA + b × yA).
  • Parallèles et perpendiculaires en cartésien : d et d′ sont parallèles si leurs coefficients (a ; b) et (a′ ; b′) sont proportionnels (ab′ − a′b = 0), perpendiculaires si aa′ + bb′ = 0.
  • Médiatrice de [AB] : droite passant par le milieu I de [AB], de vecteur normal AB.
  • Intersection de y = m₁x + p₁ et y = m₂x + p₂ : on résout m₁x + p₁ = m₂x + p₂ pour trouver x, puis on calcule y.
  • Pièges classiques : oublier le signe de p ; calculer Δx / Δy au lieu de Δy / Δx ; confondre x = k et y = k ; confondre vecteur directeur et vecteur normal.
