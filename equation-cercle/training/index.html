Équation de cercle : QCM chronométré

Séries de questions à choix multiples, une seule réponse correcte à chaque fois. Chaque erreur est corrigée avec la méthode, puis ajoutée à ton carnet pour être retravaillée plus tard.

Rappels : formules et astuces
  • Équation d’un cercle de centre Ω(a ; b) et de rayon r (repère orthonormé) : (x − a)² + (y − b)² = r². Le point M(x ; y) est sur le cercle si et seulement si ΩM² = r².
  • Lire le centre : attention aux signes. (x + 3)² = (x − (−3))², donc a = −3. Le membre de droite est r², pas r : r = √(membre de droite).
  • Centre et un point A : r² = ΩA² = (xA − a)² + (yA − b)². Inutile de calculer r.
  • Forme développée : (x − a)² + (y − b)² = r² devient x² + y² − 2ax − 2by + (a² + b² − r²) = 0.
  • Reconnaître un cercle dans x² + y² + αx + βy + γ = 0 : on complète les carrés, x² + αx = (x + α/2)² − α²/4. On obtient (x − a)² + (y − b)² = k. Si k > 0 : cercle de rayon √k ; si k = 0 : un seul point ; si k < 0 : ensemble vide.
  • Cercle de diamètre [AB] : centre au milieu I de [AB], rayon AB/2 (donc r² = AB²/4). Équivalent : M est sur le cercle si et seulement si MA · MB = 0, soit (x − xA)(x − xB) + (y − yA)(y − yB) = 0.
  • Tangente en A : elle est perpendiculaire au rayon [ΩA], donc ΩA est un vecteur normal. M est sur la tangente si et seulement si AM · ΩA = 0.
  • Intersection avec une droite : on remplace y (ou x) dans l’équation du cercle, puis on résout l’équation du second degré obtenue. Δ > 0 : deux points ; Δ = 0 : droite tangente ; Δ < 0 : aucun point.
  • Pièges classiques : oublier le changement de signe du centre ; confondre r et r² ; prendre AB comme rayon au lieu de AB/2 ; oublier la solution négative quand on résout (x − a)² = k.
