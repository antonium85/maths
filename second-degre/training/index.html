Rappels : formules et astuces
  • Trinôme f(x) = ax² + bx + c, avec a ≠ 0. Discriminant Δ = b² − 4ac.
  • Δ > 0 : deux racines x = (−b ± √Δ) / (2a). Δ = 0 : une racine double x₀ = −b / (2a). Δ < 0 : aucune racine réelle.
  • Somme et produit : x₁ + x₂ = −b/a et x₁ × x₂ = c/a. Ils servent aussi à vérifier ses racines.
  • Racine évidente : si a + b + c = 0, alors 1 est racine ; si a − b + c = 0, alors −1 est racine. L’autre racine se déduit du produit : c/a (ou −c/a).
  • Forme canonique : f(x) = a(x − α)² + β avec α = −b/(2a) et β = f(α) = −Δ/(4a). Le sommet de la parabole est (α ; β).
  • Factorisation (si Δ ≥ 0) : f(x) = a(x − x₁)(x − x₂).
  • Signe (si Δ > 0) : f(x) a le signe de a à l’extérieur des racines, et le signe contraire entre elles. Si Δ < 0, f(x) a le signe de a partout.
  • Pièges classiques : (−b)² mal calculé quand b est négatif ; signe de −4ac ; oubli du 2a au dénominateur ; bornes ouvertes ou fermées selon > ou ≥.
