Suites numériques : vitesse et précision

Séries chronométrées de questions courtes. Chaque erreur est corrigée avec la méthode, puis ajoutée à ton carnet pour être retravaillée plus tard.

Rappels : formules et astuces
  • Deux façons de définir une suite : formule explicite uₙ = f(n) (on remplace n directement) ou relation de récurrence uₙ₊₁ = f(uₙ) (on calcule les termes un par un).
  • Suite arithmétique de raison r : uₙ₊₁ = uₙ + r, donc uₙ = u₀ + nr et, plus généralement, uₙ = uₚ + (n − p)r.
  • Suite géométrique de raison q : uₙ₊₁ = q × uₙ, donc uₙ = u₀ × qⁿ et uₙ = uₚ × qⁿ⁻ᵖ.
  • Reconnaître : uₙ₊₁ − uₙ constant → arithmétique ; uₙ₊₁ / uₙ constant (termes non nuls) → géométrique. Pour montrer que ce n’est ni l’un ni l’autre, un contre-exemple sur u₀, u₁, u₂ suffit.
  • Sommes : 1 + 2 + … + n = n(n + 1)/2 ; 1 + q + … + qⁿ = (1 − qⁿ⁺¹)/(1 − q) si q ≠ 1. Termes consécutifs d’une suite arithmétique : nombre de termes × (premier + dernier)/2.
  • Sens de variation : étudier le signe de uₙ₊₁ − uₙ. Arithmétique : signe de r. Géométrique avec u₀ > 0 : croissante si q > 1, décroissante si 0 < q < 1 ; si q < 0, ni l’un ni l’autre.
  • Pourcentages : augmenter de t % revient à multiplier par 1 + t/100 ; baisser de t %, à multiplier par 1 − t/100.
  • Pièges classiques : premier terme u₁ au lieu de u₀ (exposant n − 1) ; de uₚ à uₙ il y a n − p + 1 termes ; +3 % donne 1,03 et non 1,3.
